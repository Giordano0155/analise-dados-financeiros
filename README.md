# 📈 Análise de Dados Financeiros

Projeto focado na análise de dados do mercado financeiro para identificação de tendências e padrões.

## 🎯 Objetivo
- Analisar comportamento de ativos
- Identificar tendências de mercado
- Avaliar risco e retorno

## 🛠️ Tecnologias
- Python (Pandas, Matplotlib)
- SQL (opcional)
- Power BI (futuro)

## 📊 Possíveis análises
- Média móvel
- Volatilidade
- Comparação entre ativos
